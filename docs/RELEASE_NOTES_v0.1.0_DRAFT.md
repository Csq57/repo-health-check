## Summary

Repo Health Inventory is a small, read-only Python command-line tool for maintainers who want a quick, reproducible inventory of whether a local Python repository appears to contain essential maintenance files. It uses only the Python standard library and does not execute or import the scanned project's code.

## Included in the proposed source release

- Checks for an existing README, explicit licence, GitHub Actions workflow and Python test-module filename; reports packaging, contributing and security files as optional information.
- Human-readable output and `--format json` for downstream local tooling, plus `--fail-on warning` to give warning conditions a nonzero exit code.
- Opt-in `--redact-root`, which hides the scanned root from JSON output, text output and invalid-directory error messages. Normal output remains unchanged unless the flag is used.
- Bounded discovery (20,000 files / 5,000 directories), with incomplete-scan warnings rather than unsupported assertions of absent tests.
- MIT licence for this standalone repository's scoped material, source provenance notes, contribution guidance, Issue templates and private vulnerability reporting instructions.

## Requirements and use

- **Python:** 3.11 or later.
- **Runtime dependencies:** None beyond the standard library.
- **Distribution:** source checkout or GitHub's autogenerated ZIP/tarball for an existing published tag. No `pip install` package or wheel is provided.

From a checkout, run:

```shell
python tools/repo_health_check.py .
python tools/repo_health_check.py /path/to/repository --format json --redact-root
python tools/repo_health_check.py /path/to/repository --fail-on warning
```

The tool does not connect to GitHub, call an API, or scan repositories on its own. It only inspects the local directory explicitly supplied.

## Known limitations

- File presence is not proof that tests execute, CI passes, project licensing is valid, security issues are absent or a repository is healthy in every sense.
- Symlinked directories are not followed; selected generated folders are skipped; filesystem permissions and scan limits can make the result incomplete.
- `--redact-root` protects the printed scan root, **not all filenames, source paths copied into other tools, captured terminal history or user-supplied diagnostic context**.
- This is not a malware scanner, dependency vulnerability scanner, legal certification or service with guaranteed support.
- At the 23 October 2026 preparation checkpoint, independent adoption, downloads, external contributors and ecosystem-scale use were unverified. New claims require new evidence. Neither this project nor any release implies approval for an OpenAI programme.
